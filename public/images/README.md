# Portfolio image uploads

Upload your portfolio images into this folder.

Recommended:
- Use descriptive, lowercase filenames, e.g. `luxury-fashion-homepage.jpg`.
- Prefer JPG, PNG, or WebP.
- Keep original image quality high and avoid spaces in filenames.

After uploading, images are available on the website at:
`/images/your-file-name.jpg`

For example, `public/images/project-one.jpg` is served at `/images/project-one.jpg`.

This folder is for image assets; adding an image here does not automatically create a portfolio card. The portfolio page must be updated to display each new project.
